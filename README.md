# Homebrew tap for Volyx Lens

```sh
brew install --cask dk3yyyy/volyx-lens/volyx-lens
```

Or tap first:

```sh
brew tap dk3yyyy/volyx-lens
brew install --cask volyx-lens
```

Volyx Lens is not notarised. If macOS blocks the first launch, right-click the
app and choose Open, or run `xattr -cr "/Applications/Volyx Lens.app"`.
